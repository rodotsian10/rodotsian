# RODOTSIAN PLAYROOM

모바일 중심의 개인 GitHub Pages 놀이터입니다. 빌드나 설치 없이 HTML, CSS, JavaScript로 동작합니다.

- 커다란 인스타그램 링크: @khgrecord, @rodotsian_unity
- 카드 짝 맞추기 / 반응속도 / 20초 아메 잡기
- 최고 기록은 각 브라우저의 localStorage에 저장됩니다. 저장을 차단해도 게임은 가능합니다.
- 창을 닫거나 다른 앱으로 전환하면 진행 중인 게임을 종료합니다.
- 원본 PNG는 assets에 보존하고 실제 화면에서는 가벼운 WebP를 사용합니다.

문구와 링크는 index.html, 모양은 style.css, 게임은 script.js에서 수정합니다.

## GitHub Pages 켜기

GitHub 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택하고 `main` / `/ (root)`로 저장하면 됩니다. 커스텀 도메인을 연결할 때는 Pages 설정의 Custom domain에 도메인을 입력하세요.
